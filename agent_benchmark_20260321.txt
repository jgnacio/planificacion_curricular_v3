ISSUES IDENTIFICADOS
================================================================================

Issue #1 — Espacio curricular incorrecto en respuesta (Matemática)
  Severidad: BAJA (CE y contenido son correctos)
  Descripción: En test 2.3, el agente mostró "Espacio de Comunicación" para
               una actividad de Matemática. La query Cypher retorna todos los
               tramos/unidades relacionados y el LLM prioriza el primero de la
               lista (que puede ser de otra CE con score similar).
  Causa probable: La query no filtra por espacio antes de retornar, el LLM
               mezcla múltiples resultados del TOP 5.
  Sugerencia: Añadir filtro `WHERE t.nombre CONTAINS 'Matemática'` opcional,
               o retornar solo el resultado de mayor score en el formato final.

Issue #2 — Cobertura de ingesta: Historia S.XIX / Revolución Industrial
  Severidad: MEDIA
  Descripción: El tema "Revolución Industrial y su impacto en Uruguay" está
               presente en el PDF de Historia (Tramo 4) pero no fue atomizado
               como nodo Contenido en el grafo. Puede ser que esté en una
               sección introductoria o tabla de contexto que la extracción no
               procesó.
  Acción:   Re-revisar extracción de tablas del PDF de Historia para Tramo 4,
             identificar bloques de contexto histórico siglo XIX-XX.

Issue #3 — Umbral de score inconsistente en etiqueta de confianza
  Severidad: BAJA
  Descripción: En test 4.3, el agente etiquetó score 3.97 como "Alta" pero el
               prompt define: score < 3.0 → Baja. El umbral para "Alta" no
               está definido explícitamente para el rango 3-5.
  Sugerencia: Definir en el AGENT_PROMPT:
               < 3.0  → Baja
               3.0-6.0 → Media
               > 6.0  → Alta
